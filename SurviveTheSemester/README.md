How to Run the Game
-------------------

Using Visual Studio

1. Download and extract the project folder.
2. Open SurviveTheSemester.slnx using Visual Studio.
3. Select the SurviveTheSemester project.
4. Build the solution.
5. Press Ctrl + F5 to run the game.

The game is designed for Windows because some of its console-display functionality uses Windows-specific features.
